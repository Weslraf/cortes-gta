Política de Privacidade — Cortes GTA 6

Última atualização: 10 de novembro de 2026.

1. Quem somos

"Cortes GTA 6" é um canal de fãs no YouTube e uma ferramenta interna usada apenas pelo dono do canal Cortes GTA6 para publicar e gerenciar os próprios vídeos pela YouTube Data API e pela YouTube Analytics API. O aplicativo não é oferecido ao público.

2. Quais dados o aplicativo acessa

Com a autorização do titular da conta, o aplicativo usa a YouTube Data API e a YouTube Analytics API para:

  • enviar vídeos, títulos, descrições, tags e thumbnails para o canal do próprio titular;
  • gerenciar playlists e configurações do canal do próprio titular;
  • ler informações do canal e relatórios do YouTube Analytics (visualizações, curtidas, comentários) do canal do próprio titular.

Esses dados são usados só para publicar e organizar os vídeos do próprio canal e acompanhar os resultados. Nada é vendido, compartilhado ou usado para publicidade.

O aplicativo não acessa dados de outros usuários, não coleta dados de espectadores e não exibe anúncios.

3. Como os dados são armazenados

O token de autorização fica salvo apenas no computador do titular do canal. Nenhum dado é vendido, compartilhado ou transferido a terceiros.

4. Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em security.google.com/settings/security/permissions.
